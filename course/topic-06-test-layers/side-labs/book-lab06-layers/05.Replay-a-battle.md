# Replay a battle

A **transcript** is a file with the story of a battle: for each round a line `R,<n>`, then for each
tick the `Input` line the robot saw and the `Orders` line it issued. To **replay** it, feed each
`Input` to a fresh core and compare the core's orders with the recorded ones.

Create `Replay.java` next to `LineCodec`:

```java
    public static List<Tick> run(List<String> lines) {
        List<Tick> ticks = new ArrayList<>();
        Guard guard = null;
        for (int i = 0; i < lines.size(); i++) {
            String line = lines.get(i);
            if (line.isBlank() || line.startsWith("#")) continue;
            if (line.startsWith("R,")) {
                // A new round: a new core, as the robot builds one each round.
                guard = new Guard(new Core()::tick, Telemetry.NONE);
                guard.newRound();
            } else if (line.startsWith("I,")) {
                if (guard == null) throw new IllegalArgumentException("line " + (i + 1) + ": no R line before the first tick");
                if (i + 1 >= lines.size()) throw new IllegalArgumentException("line " + (i + 1) + ": no O line after the I line");
                Input in = LineCodec.decodeInput(line);
                Orders recorded = LineCodec.decodeOrders(lines.get(i + 1));
                ticks.add(new Tick(i + 1, in, recorded, guard.tick(in)));
                i++;
            } else {
                throw new IllegalArgumentException("line " + (i + 1) + ": unexpected '" + line + "'");
            }
        }
        return ticks;
    }
```

Things to notice:

- **A new core per round.** On an `R` line it builds `new Guard(new Core()::tick, Telemetry.NONE)`,
  just as the robot does each round. The replay is faithful only if it builds the core the way
  the robot does.
- **The guard is part of the replay.** The recorded orders came out of the guard, so the replay
  goes through it too.
- **`Tick`** holds the line number, the `Input`, the `recorded` orders and the `replayed` ones.
  The class `Replay.Tick` is a small nested value; Java 17 would write it in one line as a
  `record`.
- **Strict about structure.** A tick line before any `R`, or an `I` line with no `O` line after it,
  throws `IllegalArgumentException` with the line number.
- Blank lines and `#` comments are ignored, so a transcript can carry a note.

`Replay` is in the **main** code of the core because the bench and tools can use it. It does
no I/O: it takes a `List<String>`. Reading the file is the test's business. ArchUnit (Lab 05)
would tell you if you broke that.

## A transcript to commit

The folder `src/test/resources/replay/` holds `scripted-duel.txt`. It is a **scripted** two-round duel:
inputs made up by a program, orders as the core gave them when the file was made. A script
(`ScriptedBattle.java` in the test folder) creates it, so that you can see how, and can
remake it; copy it from `course-labs/lab-06` together with the transcript.

Generate it yourself, from the lab folder, after `mvn -B test-compile`:

```bash
java -cp hadurling-core/target/classes:hadurling-core/target/test-classes \
  hadurling.core.replay.ScriptedBattle \
  hadurling-core/src/test/resources/replay/scripted-duel.txt
```

Open the file. It starts:

```text
# A scripted two-round duel. Made by ScriptedBattle; do not edit by hand.
R,0
I,0,200.0,150.0,0.0,5.0,100.0,0.0,0.0,0.0,
O,NaN,100.0,NaN,Infinity,0.0
```

You can read a tick: at time 0 the robot is at (200, 150), saw nothing, and the core ordered
"drive 100, sweep the radar forever, hold fire".

## The test

```java
package hadurling.core.replay;

import static org.junit.jupiter.api.Assertions.assertEquals;
import static org.junit.jupiter.api.Assertions.assertFalse;
import static org.junit.jupiter.api.Assertions.assertNotEquals;
import static org.junit.jupiter.api.Assertions.assertThrows;

import java.io.IOException;
import java.io.InputStream;
import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.List;
import org.junit.jupiter.api.DisplayName;
import org.junit.jupiter.api.Test;

/**
 * A recorded battle is a regression test for the whole core at once: replay it through a fresh
 * core and the orders must be exactly the recorded ones.
 */
class ReplayTest {

    private static List<String> transcript() throws IOException {
        try (InputStream in = ReplayTest.class.getResourceAsStream("/replay/scripted-duel.txt")) {
            String text = new String(in.readAllBytes(), StandardCharsets.UTF_8);
            return List.of(text.split("\\R"));
        }
    }

    @Test
    @DisplayName("replaying the scripted duel reproduces the recorded orders")
    void replayMatchesRecording() throws IOException {
        List<Replay.Tick> ticks = Replay.run(transcript());
        assertEquals(100, ticks.size());
        for (Replay.Tick t : ticks) {
            assertEquals(t.recorded(), t.replayed(), "line " + t.line());
        }
    }

    @Test
    @DisplayName("two replays give the same orders")
    void replayIsDeterministic() throws IOException {
        List<String> lines = transcript();
        List<Replay.Tick> a = Replay.run(lines);
        List<Replay.Tick> b = Replay.run(lines);
        for (int i = 0; i < a.size(); i++) assertEquals(a.get(i).replayed(), b.get(i).replayed());
    }

    @Test
    @DisplayName("a changed recording is noticed: the test can fail")
    void changedRecordingIsDetected() throws IOException {
        List<String> lines = new ArrayList<>(transcript());
        int firstOrders = lines.indexOf(lines.stream().filter(l -> l.startsWith("O,")).findFirst().get());
        lines.set(firstOrders, "O,0.0,1.0,0.0,0.0,3.0");
        List<Replay.Tick> ticks = Replay.run(lines);
        assertNotEquals(ticks.get(0).recorded(), ticks.get(0).replayed());
    }

    @Test
    @DisplayName("the scripted duel covers both a visible and a hidden enemy")
    void scriptCoversHiddenEnemy() throws IOException {
        List<Replay.Tick> ticks = Replay.run(transcript());
        assertFalse(ticks.stream().allMatch(t -> t.input().events().isEmpty()));
        assertFalse(ticks.stream().allMatch(t -> !t.input().events().isEmpty()));
    }

    @Test
    @DisplayName("a transcript with an I line but no O line is rejected")
    void missingOrders() {
        List<String> lines = List.of("R,0", "I,0,1,1,0,0,100,0,0,0,");
        assertThrows(IllegalArgumentException.class, () -> Replay.run(lines));
    }
}
```

- `replayMatchesRecording` is the point: 100 ticks, each must match.
- `changedRecordingIsDetected` checks the checker: it doctors one recorded `O` line and asserts
  that the replay *notices*. A test that cannot fail is worth nothing, so test that it can.
- `scriptCoversHiddenEnemy` checks the script has ticks with and without events, otherwise
  the fixture would not exercise the radar-sweep branch at all.

The test loads the transcript from the classpath with `getResourceAsStream("/replay/...")`:
everything under `src/test/resources` is on the test classpath, whatever the folder depth.
