# Lab 06: Testing in layers

You have unit tests, a determinism test and architecture rules. In this lab you add two more
layers, each catching what the others cannot: **property tests** with your own generators, and a
**replay test** that runs a whole recorded battle through the core and demands the same orders.
Both depend on the core having no engine, which is what Lab 04 bought.

## Objectives

By the end of this lab you can:

- write a text format for a value and a codec that reads and writes it
- write a jqwik round-trip property with custom `Arbitrary` generators
- say what shrinking is, and what a generator must include to be useful
- record a battle as text and replay it through a fresh core
- explain what each layer of tests catches that the others miss

## What you start from

`course-labs/lab-05`, or this lab's `archives/start.zip`.

## What you will have at the end

- `hadurling.core.replay.LineCodec`: an `Input` or `Orders` as one text line, and back
- `hadurling.core.replay.Replay`: runs a transcript through a fresh core
- `LineCodecProperties`, `LineCodecTest`, `ReplayTest`, and a committed transcript
  `scripted-duel.txt` in `src/test/resources/replay/`
- `HadurlingRecorder` in the robot module: writes a transcript from a real battle

This is `course-labs/lab-06`.
