# Exercises

## 1. A property for the guard

Write a jqwik property: for any `Input` from the generators and a core that always throws, the
guard returns orders with `firePower() == 0` and a finite `ahead`. (Copy the generators into a
shared test class, or make them `static` and package-visible in `LineCodecProperties`, so two
property classes can use them.)

## 2. Model-based testing

A *model-based* property checks fast code against slow, obviously correct code. Write a property
that `Angles.normalRelativeAngle(a)` equals a slow version that subtracts `2 pi` in a `while`
loop until the angle is below `pi`, and adds it while below `-pi`. Use angles in `[-1000, 1000]`.
Which has the better tolerance, and why is exactness not demanded this time?

## 3. A second transcript

Record a real battle with `HadurlingRecorder` against `sample.Walls`. Add it under
`src/test/resources/replay/` and a parameterised `ReplayTest` (JUnit's `@ParameterizedTest` with
`@MethodSource`) that replays each transcript in the folder. List the folder from the classpath
with `getResource("/replay")`. Add a test that the folder has at least two files.

## 4. Compress it

Real transcripts get large. Hadur stores them gzipped (`.txt.gz`). In the test (not the core:
the core does no I/O) read a `.txt.gz` with `java.util.zip.GZIPInputStream`, and write a tiny
tool that zips the plain file. How much smaller is it?
