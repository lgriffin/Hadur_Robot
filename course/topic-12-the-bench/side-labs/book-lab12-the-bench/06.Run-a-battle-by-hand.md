# Run a battle by hand

This step is not part of `mvn verify`. Do it once to see the numbers.

You need a JDK from 17 to 21 (check `java -version`). First build the robot's jar:

```sh
cd course-labs/lab-12
mvn -B package -DskipTests
```

That produces `hadurling-robot/target/hadurling.Hadurling_0.1.jar`. Then run the bench:

```sh
cd hadurling-bench
mvn -B -q exec:java -Dexec.args="--opponent sample.Crazy,sample.Walls --rounds 10 --seeds 5"
```

It prints one line per battle as it goes:

```
  candidate vs sample.Crazy seed 1: 93.4%
  candidate vs sample.Crazy seed 2: 88.0%
  ...
```

and then a report: a table with one row per opponent and an overall row, each as
`mean +/- half-width (n=5)`. Each battle takes a few seconds with 10 rounds. Everything it makes goes
in `work/<time>`, which is in `.gitignore`: the engine log of each battle is in there if one fails.

## A/B against an older lab

Build lab 07 too (`mvn -B package -DskipTests` in `course-labs/lab-07`) and pass its jar:

```sh
mvn -B -q exec:java -Dexec.args="--opponent sample.Crazy,sample.Walls --rounds 10 --seeds 5 \
  --baseline-jar ../../lab-07/hadurling-robot/target/hadurling.Hadurling_0.1.jar \
  --baseline-name lab-07 --candidate-name lab-12"
```

Both jars are called `hadurling.Hadurling` version 0.1. The bench installs each in a Robocode home of
its own (`work/<time>/candidate` and `work/<time>/baseline`) so that they do not overwrite each other.

The author ran this in a sandbox with JDK 21, 10 rounds and seeds 1 to 3, warm. Lab 12 scored 92.0%
+/- 12.4, lab 07 scored 54.3% +/- 8.9, and the paired difference was +37.8 +/- 16.2 points. The
whole interval is above zero, so the bench called it **better, outside the noise**. Your numbers will
differ with your machine and Robocode build, but the direction should hold.

Notice what the interval says. With three seeds the interval on the difference is +/- 16 points
wide. That is honest. Run more seeds and it narrows.

## If it does not run

- **"No robot jar at ..."** You skipped `mvn package`, or the jar is in another place: use
  `--robot-jar`.
- **The security manager complaint** You are on a JDK newer than 21. Switch to 17 to 21.
- **`ERROR expected 2 robots, found ...`** The opponent's name is wrong. Names are as Robocode lists
  them, for example `sample.Crazy`.
- **A battle times out.** The bench gives each one 30 minutes, then stops it and says which. Check
  `work/<time>/engine-*.log`.
