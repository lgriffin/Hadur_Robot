## Student's t

With `n` samples, the 95% interval for the mean is `mean +/- t * s / sqrt(n)`, where `s` is the
standard deviation of the samples (dividing by `n - 1`) and `t` depends on `n`. For large `n`, `t`
is 1.96. For small `n` it is bigger, and that matters: five seeds is a small sample.

| Samples | t (95%) |
|---------|---------|
| 2 | 12.706 |
| 3 | 4.303 |
| 5 | 2.776 |
| 10 | 2.262 |
| 30 | 2.045 |

Using 1.96 for five seeds would make every interval about 30% too narrow, and every conclusion about
30% too keen. The class carries a small table:

```java
private static final double[] T975 = {
    Double.NaN, 12.706, 4.303, 3.182, 2.776, 2.571, 2.447, 2.365, 2.306, 2.262, 2.228,
    ...
};
```

indexed by degrees of freedom (`n - 1`), and falls back to 1.96 above the table.

## The method

```java
public static Stats of(List<Double> xs) {
    int n = xs.size();
    if (n == 0) return new Stats(0, Double.NaN, Double.NaN);
    double sum = 0;
    for (double x : xs) sum += x;
    double mean = sum / n;
    if (n == 1) return new Stats(1, mean, Double.NaN);
    double squares = 0;
    for (double x : xs) squares += (x - mean) * (x - mean);
    double sd = Math.sqrt(squares / (n - 1));
    double t = n - 1 < T975.length ? T975[n - 1] : 1.96;
    return new Stats(n, mean, t * sd / Math.sqrt(n));
}
```

Two lines are requirement `HL-34`. With no samples the mean is NaN. With one sample the mean is
known and the half-width is `NaN`, **not 0**. Everything that prints it must cope.

```java
public String percent() {
    if (n == 0) return "n/a";
    String m = String.format(Locale.ROOT, "%.1f%%", mean * 100);
    String h = Double.isNaN(halfWidth) ? "?" : String.format(Locale.ROOT, "%.1f", halfWidth * 100);
    return m + " +/- " + h + " (n=" + n + ")";
}
```

`Locale.ROOT` is on purpose. A machine set to a locale that writes `55,0` would print different
numbers from yours, and a test that compares strings would fail on it.

## Test it with a number you worked out by hand

```java
@Test
@Tag("HL-33")
@DisplayName("five samples: the mean, and a half-width of t(4) * s / sqrt(5)")
void fiveSeeds() {
    Stats s = Stats.of(List.of(0.50, 0.60, 0.55, 0.52, 0.58));
    assertEquals(5, s.n());
    assertEquals(0.55, s.mean(), 1e-12);
    // Sum of squared deviations 0.0068, so s = sqrt(0.0068 / 4) = 0.04123; t(4) = 2.776.
    assertEquals(2.776 * Math.sqrt(0.0068 / 4) / Math.sqrt(5), s.halfWidth(), 1e-9);
}
```

Work out the 0.0068 yourself on paper before you trust the test. A test whose expected value came
from the code under test checks nothing.

The other `StatsTest` examples:

- identical samples have a mean and no spread (`HL-33`)
- more samples of the same spread give a narrower interval (`HL-33`)
- one sample or none: the interval is unknown, never zero (`HL-34`)
- `percent()` formats the mean and the interval: `"55.0% +/- 5.1 (n=5)"`
