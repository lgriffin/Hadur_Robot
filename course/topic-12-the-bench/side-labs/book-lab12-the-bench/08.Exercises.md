# Exercises

1. **More seeds.** Run the step 6 command with `--seeds 10` and compare the width of the interval
   with the `--seeds 5` run. How much narrower? The width should shrink roughly with the square
   root of the number of seeds. Does it?
2. **A change that does nothing.** Fight lab 12 against lab 12 as baseline and candidate. What
   should the paired difference be? What does the verdict say? Run it.
3. **A change that hurts.** Make the gun in a copy of lab 12 fire at a random angle. Build the jar
   and run an A/B. Does the bench call it worse, and with how many seeds?
4. **The wrong test.** Change `Report.compare` to take the difference of the two means rather than
   the mean of the differences. Does your answer for a list of 5 seeds change? When would it?
5. **Warm versus cold.** Run the same command with and without `--warm`. Why might the warm result
   be higher? Which one would you use to compare two versions, and why?
6. **A sparring partner.** Write a small robot of your own that only runs in a circle. Pass its jar
   with `--opponent-jar` and fight it. What does the share tell you about Hadurling? What does it not
   tell you?
7. **A requirement for the report.** Write `HL-36` in EARS for "the report shall say how many seeds
   were fought". Tag the test.
