# Exercises

1. **Version 3.** Add a field to the profile, say the number of rounds we won, as version 3. Which
   methods change? Which existing tests must still pass without being edited? Write the property
   that a version 2 file loads with the new field at its default.
2. **Remove the temporary copy.** Make `save` write only the real file. Run
   `aSaveKilledAnywhereLeavesTheOldOrTheNewProfile`. What is the shortest failing case?
3. **Delete before write.** In `save`, delete the real file first, then write. What fails, and what
   does the shrunk counterexample look like?
4. **Two bits.** The CRC property flips one bit. Write a property that flips two. Does CRC-32 still
   catch all of them? What does your answer say about "every changed bit"?
5. **A hostile name.** Add a robot name that is 10,000 characters long, one that is only spaces and
   one with a null character. What does `LineageKey.of` give? Does any of them reach the file
   system?
6. **A slow store.** Suppose each `read` took 5 ms. How long does it take to load 100 profiles? The
   next lab times a battle; where in this design would the cost show?
