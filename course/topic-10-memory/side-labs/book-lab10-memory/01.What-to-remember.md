# What to remember

A robot has a few kilobytes of disk per opponent, in a directory Robocode gives it, and no other
place to keep anything between battles. Spend them on what the next battle can use.

## The profile

```java
public Profile(String key, int rounds, int theirShots, int theirHits, int ourShots,
        int ourHits, List<float[]> seed)
```

- `key`: who the opponent is (more below)
- `rounds`: how many rounds we have met it
- `theirShots`, `theirHits`: how often it fired and how often it hit us
- `ourShots`, `ourHits`: the same, for us
- `seed`: up to 100 samples of what our gun learned, three floats each (the two features and the
  guess factor)

`Profile` is immutable and checks itself in the constructor. Hits cannot exceed shots, counts
cannot be negative, a sample must have three finite floats, and the seed is capped:

```java
public static final int SEED_WIDTH = 3;
public static final int MAX_SEED = 100;
```

Why validate here? Because the bytes come off a disk. A profile that is constructed is a profile
that makes sense, and the codec can rely on that. The caps keep a profile small, so a hundred
opponents fit in the quota.

A round adds to the profile by making a new one:

```java
public Profile afterRound(int theirShots, int theirHits, int ourShots, int ourHits, List<float[]> newSeed)
```

The counts add up, the seed is replaced by the newest samples.

## What can go wrong

Write the list before you write the code, because each item becomes a requirement and a test:

1. The file is cut short, because the robot was killed during a save.
2. A byte changes on disk.
3. The file was written by an older version of Hadurling, with fewer fields.
4. The file is from a much newer version we do not know.
5. There is no file at all: a stranger.
6. The store throws: no directory, quota exceeded, a file locked.
7. The disk is full of other opponents' profiles.
8. Two opponents' names map to the same file name.

Number 1 is the hardest, so the design starts there: never overwrite the only good copy until the
new one is complete.
