# Exercises

1. **A different interval.** Replace Agresti-Coull with the Wilson score interval. The tests for
   `HL-25` that check the exact formula should fail and the others should not. Which is which, and
   what does that say about the tests that did not fail?
2. **Window size.** Change `HitWindow.DEFAULT_CAPACITY` from 100 to 20. Run the tests. Which fail? Is
   the rule in `SeedTrust` still reachable at 20? Write down the widest margin a window of 20 can
   have.
3. **The lower bound.** The policy uses `lower()` of our rate and `upper()` of theirs. Why not use
   the raw rate for both? Write a test where the raw rates would say "fire full power" and the
   bounds say "hold back".
4. **A third policy.** Write `HL-33` and a small policy that holds the radar sweep narrow only when
   the enemy's last 20 scans were all close. Write the thin-evidence test first.
5. **Reachability.** Write the "can it fire" test for the full-power rule: build the most favourable
   window for ours and theirs that 100 outcomes allow, and check that `certain` is true. Then find
   the smallest window that makes it true.
6. **Fade the other way.** Seed weight never grows back. Argue for or against letting it recover
   when the live evidence agrees again. What would the new requirement say?
