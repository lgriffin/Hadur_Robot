# Wire it in

Two places change: the gun and the core.

## The gun takes its power

`aim` now takes the power as an argument:

```java
public Aim aim(Input in, Event.Scan scan, double power)
```

The old fixed `POWER` constant stays as the default. The gun still decides whether to fire (it
returns 0 while the barrel is hot or off target). The core decides how hard.

## The core asks the policy

```java
double power = PowerPolicy.power(GuessFactorGun.POWER, evidence.ours().estimate(),
    evidence.theirs().estimate(), in.energy(), scan.energy());
GuessFactorGun.Aim aim = gun.aim(in, scan, power);
```

That is requirement `HL-32`. The two windows are fed by the outcomes the gun and the surfer already
report (lab 10 added them for the profile):

```java
for (boolean hit : surfer.advance(in)) {
    theirShots++;
    if (hit) theirHits++;
    evidence.theirs().record(hit);
}
...
for (boolean hit : gun.observe(in, scan)) {
    ourShots++;
    if (hit) ourHits++;
    evidence.ours().record(hit);
    if (trust != null && trust.observe(evidence.ours().estimate())) gun.seedWeight(trust.weight());
}
```

`meet` (the first scan of an opponent) now makes the trust, from the profile's own record:

```java
String key = LineageKey.of(scan.name());
evidence.against(key);
profile = library == null ? Profile.stranger(key) : library.load(key);
if (!profile.seed().isEmpty()) {
    gun.seed(profile.seed());
    trust = new SeedTrust(Estimate.of(profile.ourHits(), profile.ourShots()));
}
```

Two small things. `evidence.against(key)` clears the windows if this is a different opponent. And
`Core` now has a second constructor, `Core(ProfileLibrary, Evidence)`, so that the evidence can
outlive a round.

## Why the evidence is passed in

A new `Core` is made every round. The windows must **not** be: the point of a window of 100 is that
it spans rounds. So `Hadurling` holds the evidence in a `static` field, next to the library, and
hands it to each new core:

```java
private static final Evidence evidence = new Evidence();
...
core = new Core(library, evidence);
```

Tests make their own `Evidence` and need no static state.

Note that `Core(null)` still works and still behaves as before when the evidence is thin, which
at the start of a battle it always is. That is why the replay fixture does not change in this lab:
the scripted battle is too short for any rate to become certain, so the policy keeps the gun's power.
