# Tests, and verify

## A test double

`GuardTest` needs a core that fails. It does not use the real `Core`: a lambda that throws is
enough. A stand-in written for a test is a **test double**.

```java
    private static final Function<Input, Orders> THROWS = in -> {
        throw new IllegalStateException("boom");
    };
```

The tests then cover each promise of the guard:

```java
    @Test
    @DisplayName("when the core throws, the guard returns safe orders: drive, no fire")
    void safeOrdersOnThrow() {
        Guard guard = new Guard(THROWS, line -> { });
        Orders o = guard.tick(input(1, 0));
        assertEquals(Guard.SAFE_DISTANCE, o.ahead());
        assertEquals(0, o.firePower());
        assertEquals(Double.POSITIVE_INFINITY, o.radarTurn());
    }
```

Write the others from the description in step 5: safe orders keep the direction of travel; a
`null` result counts as a fault; an `Error` is caught; faults are logged once per round and counted every
tick (use a `List<String>` and `log::add` as the telemetry, which is how a test collects a
port's output); and the safe orders lock onto an enemy seen on the failing tick. The file in
`course-labs/lab-04` has all seven.

Move the gun and movement into `CoreTest` too: rename the class, replace `new Brain()` with `new Core()`
and `think` with `tick`. All its tests should still pass.

## Verify

Run from the parent folder:

```bash
mvn -B verify
```

Maven prints a reactor summary: `Hadurling (lab 04)`, `Hadurling core (lab 04)` and
`Hadurling robot (lab 04)`, all `SUCCESS`. **Passing looks like** `Tests run:` totals for the core
(about 30) and 1 for the robot, then `BUILD SUCCESS`.

Check the jar:

```bash
unzip -l hadurling-robot/target/hadurling.Hadurling_0.1.jar | grep -E "Core|Guard|properties"
```

You should see `hadurling/core/Core.class`, `hadurling/core/Guard.class` and
`hadurling/Hadurling.properties`. Load the jar into Robocode as in Lab 01: it fights as before.

## Prove the wall is real

Add `import robocode.AdvancedRobot;` to `Core.java` and run `mvn -B compile`. It fails:
`package robocode does not exist`. That error is the hexagon. Remove the import.
