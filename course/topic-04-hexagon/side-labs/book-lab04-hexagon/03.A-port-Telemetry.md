# A port: Telemetry

The brain sometimes wants to say something: "the core crashed". It must not print to the console
itself, because that is the outside world's business. So we give it a **port**: an interface
that says what it needs.

Create `hadurling-core/src/main/java/hadurling/core/port/Telemetry.java`:

```java
package hadurling.core.port;

/**
 * Where the core sends its log lines. A <em>port</em>: the core says what it needs (somewhere
 * to put a line of text) and the adapter decides what that is. In the robot it is the
 * robot's console; in a test it is a list.
 */
@FunctionalInterface
public interface Telemetry {

    /** Discards every line. */
    Telemetry NONE = line -> { };

    /**
     * Records one line.
     *
     * @param line a single line of text, without a line terminator
     */
    void emit(String line);
}
```

## Interface, lambda, constant

- An **interface** lists methods without bodies. Whoever implements it fills them in.
- `@FunctionalInterface` marks an interface with exactly one abstract method. Such an interface
  can be written as a **lambda**: `line -> out.println(line)` is a `Telemetry` whose `emit` prints.
  You will do exactly that in the adapter.
- `NONE` is a constant implementation that discards everything: `line -> { }`. Tests and replays
  that do not care about the log pass `Telemetry.NONE`. This is the **null object** pattern: an
  object that does nothing, so callers never check for `null`.

The package is called `port` on purpose. A package of interfaces is the doorway: look in it and
you see everything the core asks of the world.
