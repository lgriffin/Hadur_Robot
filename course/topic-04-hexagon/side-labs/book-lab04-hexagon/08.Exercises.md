# Exercises

## 1. A fault report with more detail

The guard logs `FAULT,<tick>,<exception class>`. Add the exception's message too, taking care of
commas (they would break a comma-separated line; replace them). Write the test first, using a
`Function` that throws `new IllegalStateException("a,b")`.

## 2. Fire back when the core is down

After three faulting ticks in a round, the guard's safe orders could turn the gun to the enemy's
last bearing and fire power 1 when the gun is cool. You need the gun heat and the gun heading from the
`Input`; both are there. Write a test that three faults produce `firePower() == 1`, and that the
first and second faults do not.

## 3. A second port

Create a port `Clock` in `...core.port` with `long now()` and use it in the guard to put a time
on each fault line. Tests give it a fixed clock (a lambda). Why is it better than the guard calling
`System.nanoTime()` itself? (Lab 05 will make calling it from the core a build failure.)

## 4. Recovery

When a core fails, its state may be damaged. Give the guard a second function, a `Runnable
recover`, that it calls on the next tick with a scan. In the robot make it replace the core
with `new Core()`. Test that a core that throws once then works is called again after recovery
with fresh state.
