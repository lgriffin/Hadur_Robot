# Exercises

## 1. Escape angle in degrees

Write a test that checks `Rules.maxEscapeAngle(1.0)` in **degrees** against a value you compute
with a calculator. Make sure you understand which one of `Math.toDegrees`/`Math.toRadians` goes
where. What happens to the angle as the power approaches 0.1? Explain it in one sentence in
the test's `@DisplayName`.

## 2. More properties

Add properties to `AnglesMatchEngineProperties` or a new `AnglesProperties` that do not need the
engine at all:

- the result of `normalRelativeAngle` is always in [-pi, pi)
- `normalRelativeAngle(a + 2 pi)` equals `normalRelativeAngle(a)` within `1e-9`
- `absoluteBearing(x1, y1, x2, y2)` and `absoluteBearing(x2, y2, x1, y1)` differ by exactly pi
  (modulo 2 pi)

The last one may fail on a first try. Why? (Floating point: use a tolerance.) A property that
fails is a gift: either your code or your claim is wrong.

## 3. Where will we hit the wall?

Add `Field.distanceAlong(double x, double y, double heading)`: how far a robot at (x, y) can
drive on that heading before it reaches the edge of the reachable area. Hint: for each of the
four walls that the heading points toward, work out the distance with `Math.sin` and
`Math.cos`, and take the smallest. Test the four compass directions first (distances you can
check by eye), then a diagonal.

This is the start of wall-stop prediction, which Hadur uses to keep its movement from ending in a
wall.
