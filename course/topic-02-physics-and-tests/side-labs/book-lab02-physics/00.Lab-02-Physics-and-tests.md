# Lab 02: Physics and tests

In Lab 01 you borrowed `robocode.util.Utils` to fold angles. Here you write that code
yourself, in plain Java, and prove it right with tests. You also add the bullet rules and the
walls. Nothing in this lab needs the engine to run, which is the point: pure functions can be
tested in milliseconds, thousands of times.

## Objectives

By the end of this lab you can:

- write a static utility class of pure functions (numbers in, numbers out)
- explain why floating point needs a tolerance in tests, and when exact equality is right
- write JUnit 5 tests with `@Test`, `@DisplayName` and `assertEquals`
- write a jqwik property that checks your code against a trusted one on random inputs
- run the tests with Maven and read the result

## What you start from

`course-labs/lab-01` in the Hadur repository, or this lab's [`start.zip`](./archives/start.zip): the robot
from Lab 01, in one class.

## What you will have at the end

- a new package `hadurling.physics` with `Angles`, `Rules` and `Field`
- 15 tests, among them 4 jqwik properties, that run on `mvn verify`
- `Hadurling` using `Angles` instead of the engine's `Utils`

This is `course-labs/lab-02`.

## The steps

1. Set up the test layout
2. Angles
3. Test Angles
4. Rules
5. Field
6. A property: our angles equal the engine's
7. Use it in the robot, and verify
8. Exercises
9. Compare with Hadur
