# Angles

Create `src/main/java/hadurling/physics/Angles.java`. It is a **utility class**: only static
methods, no fields that change, never instantiated. That is why the constructor is `private`
and the class is `final`: nobody can make an object of it or extend it.

## Two normalisations

An angle can be any number: 7 radians is the same direction as 7 - 2 pi = 0.72. We want a
single standard form. There are two, for two jobs:

- **absolute**, in [0, 2 pi): for compass directions. "Where is the enemy?"
- **relative**, in [-pi, pi): for turns. "How far, and which way, must I turn?" The sign says
  which way (positive is clockwise), the size is the short way round.

```java
public final class Angles {

    /** One full turn, in radians. */
    public static final double TWO_PI = 2 * Math.PI;

    private Angles() {}

    // the methods go here
}
```

The `private` constructor and `final` class stop anyone creating or extending it. Now the
first method. Understand the `%` before you type it.

## Java's `%` keeps the sign

In maths, 7 mod 2 pi is positive. In Java, `-1 % 6.28` is `-1`, not `5.28`: the result takes
the sign of the left side. So after `angle %= TWO_PI` an absolute angle can still be
negative, and we add one more turn to fix it:

```java
    public static double normalAbsoluteAngle(double angle) {
        // Java's % keeps the sign of the dividend, so a negative angle comes out in
        // (-2 PI, 0) and needs one more turn added.
        angle %= TWO_PI;
        return angle >= 0 ? angle : angle + TWO_PI;
    }
```

Now the relative one. After `%`, the angle is somewhere in (-2 pi, 2 pi). Fold each half:

```java
    public static double normalRelativeAngle(double angle) {
        angle %= TWO_PI;
        // Now the angle is in (-2 PI, 2 PI). Fold each half into [-PI, PI). Exactly PI maps
        // to -PI, as in the engine: the interval is closed below and open above.
        if (angle >= 0) {
            return angle < Math.PI ? angle : angle - TWO_PI;
        }
        return angle >= -Math.PI ? angle : angle + TWO_PI;
    }
```

Exactly pi maps to **minus** pi. That looks odd, but it is what the engine does, and we want
to be identical to it: the interval is closed at the bottom and open at the top.

## Absolute bearing

One more function: the compass direction from one point to another. Schools teach
`atan2(dy, dx)`, where 0 points east and angles grow anticlockwise. Robocode's compass is
rotated: 0 is north and angles grow clockwise. Swapping the arguments, `atan2(dx, dy)`, does
the rotation:

```java
    public static double absoluteBearing(double fromX, double fromY, double toX, double toY) {
        // atan2(dx, dy), with the arguments the "wrong" way round for maths but right for
        // a compass: zero points up the y axis and angles grow clockwise.
        return normalAbsoluteAngle(Math.atan2(toX - fromX, toY - fromY));
    }
```
