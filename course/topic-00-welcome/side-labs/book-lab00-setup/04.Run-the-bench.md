# Run the bench

Watching a battle shows you a picture. The bench gives you numbers. It runs **real Robocode battles, headless** (no window), many times, and reports score share with a margin of error. Every Hadur stage was gated on it.

## What it does

The bench runs the full Robocode 1.9.5.6 engine from Maven Central, with the security manager on. Each battle runs in its own JVM with a fixed random seed, so the same command gives the same result every time. You do not need your Robocode install for this. It uses its own copy.

In **cold** mode the bench wipes Hadur's data directory before every battle, so Hadur meets each opponent as a stranger. `--mode warm` would keep what it learned.

## Build the jar first

From the repository root:

```sh
mvn package -DskipTests
```

## Run a short bench against the sample bots

```sh
cd hadur-bench
mvn exec:java -Dexec.args="--mode cold --only sample. --rounds 10 --seeds 1"
```

What the options mean:

| Option | Meaning |
|---|---|
| `--mode cold` | wipe Hadur's data before each battle |
| `--only sample.` | run only opponents whose name contains `sample.`, the five bundled sample bots |
| `--rounds 10` | 10 rounds per battle (the default is 35) |
| `--seeds 1` | 1 battle per opponent (the default is 5) |

The command exits non-zero if any battle fails. The first run downloads Robocode from Maven Central.

The full bench from the README is the same command without the shortcuts:

```sh
mvn exec:java -Dexec.args="--mode cold --rounds 35 --seeds 5"
```

That list also names abc.Shadow 3.83c, a third-party robot whose jar is not in the repository. Put it in `hadur-bench/opponents/` to include it. You do not need it for this lab.

## Read the report

The bench writes a working directory under `hadur-bench/work/cold-<time>/`. Open `report.md` there. It has a table with one row per opponent: score share, survival share, rounds won, skipped turns and more.

For the sample bots you should see score shares in the high 90s and nearly every round won. In the S0 baseline for Hadur 1.20, the sample bots gave 97% to 99.8% score share (`docs/bench/s0-baseline-1.20-cold.md`).

## Why this matters

You will meet this bench again in Topic 12, where you build a small version for Hadurling. For now, the point is that "does it work?" has a number for an answer, with an interval, and the number is repeatable.

## Check yourself

- The bench finished without an error
- You found `report.md` and can say which opponent Hadur scored highest against
