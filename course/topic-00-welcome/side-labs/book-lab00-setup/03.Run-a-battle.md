# Run a battle

Now watch the robot you just built fight.

## Put the jar where Robocode can see it

Copy the jar into Robocode's `robots` folder:

```sh
cp hadur-robot/target/hadur2.Hadur_3.9.jar /path/to/robocode/robots/
```

On Windows, copy the file in Explorer instead. Use your own Robocode folder in place of `/path/to/robocode`.

If Robocode was open, close it and start it again. If Hadur still does not appear in the next step, use the menu **Options > Clean robot cache** and restart.

## Start a battle against sample.Crazy

1. Start Robocode (`robocode.sh` or `robocode.bat`)
2. Choose **Battle > New**
3. In the left list, open the **hadur2** package and select **hadur2.Hadur 3.9**. Click **Add >>**.
4. Open the **sample** package, select **sample.Crazy**, and click **Add >>**
5. Click **Next**, leave the defaults (35 rounds, 800 x 600 is what the bench uses), and click **Start Battle**

Watch a few rounds. Hadur should win nearly every round against `sample.Crazy`. At the end, the results window shows the scores.

## Then sample.SpinBot

Repeat the steps with **sample.SpinBot** instead of `sample.Crazy`. Both are sample robots that ship with Robocode.

## What to notice

- Hadur keeps its distance and orbits
- It hits the sample bots most of the time
- The bench measured it winning 875 of 875 sample-bot rounds at release 2.2 (`docs/strategy-evolution.md`)

You can also run Hadur against yourself later. For now, you have seen the thing you will spend the course understanding.

## Check yourself

- Hadur appears in the robot list
- You watched it beat `sample.Crazy` and `sample.SpinBot`
