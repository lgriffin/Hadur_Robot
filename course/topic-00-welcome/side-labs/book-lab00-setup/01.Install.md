# Install

You need four things. Install them in this order.

## 1. A JDK 17

Hadur builds with Java 17 or later. The robot itself is compiled for Java 11 so every RoboRumble client can load it, but the build and the tests run on 17.

Install any JDK 17 (for example Eclipse Temurin 17). Then check:

```sh
java -version
```

The first line should say `17` or higher.

## 2. Maven 3.9

Install Apache Maven 3.9 from [maven.apache.org](https://maven.apache.org/download.cgi) or your package manager. Then check:

```sh
mvn -version
```

It should report Maven 3.9 and the same Java version you just installed. If it shows an older Java, set `JAVA_HOME` to the JDK 17 folder and open a new terminal.

## 3. Robocode 1.9.5.6

Download the Robocode 1.9.5.6 installer from [sourceforge.net/projects/robocode/files/](https://sourceforge.net/projects/robocode/files/). Open the `1.9.5.6` folder and take the setup jar. Run it with Java and follow the installer:

```sh
java -jar robocode-1.9.5.6-setup.jar
```

(The file name may differ slightly. Use whatever the `1.9.5.6` folder offers.) Remember where you installed it. This course calls that folder `robocode/`. The folder holds `robocode.sh` and `robocode.bat` and a `robots/` folder.

Start it once to check it opens:

```sh
cd robocode
./robocode.sh      # Windows: robocode.bat
```

You should see the Robocode window with a battlefield.

## 4. An IDE

Any IDE that opens Maven projects works. IntelliJ IDEA Community and Eclipse are both fine, and so is VS Code with the Java extensions. Open it once and check it can see your JDK 17.

## Check yourself

- `java -version` shows 17 or higher
- `mvn -version` shows Maven 3.9
- The Robocode window opens
