# Get the lab code

The lab code is in the Hadur repository you already cloned, in the `course-labs` folder.

## Look at what is there

```sh
cd ..                 # back to the repository root
ls course-labs
```

You will see one folder per lab, named `lab-00`, `lab-01` and so on, plus `tools/` and an `AUTHORING.md`.

## How the folders relate

- `lab-NN` is the **solution** of Lab NN
- It is also the **start** of Lab NN+1
- So you begin Lab 01 from `lab-00`, and you begin Lab 02 from `lab-01`

If you fall behind, copy the previous folder and carry on from there. Each folder is a standalone Maven project with a `README.md` that says what changed since the one before.

## Check that lab-00 builds

```sh
cd course-labs/lab-00
mvn -B verify
```

You should see `BUILD SUCCESS`. Lab 00's robot, `hadurling.Hadurling`, extends `AdvancedRobot` and only spins its radar. It is the skeleton that Lab 01 turns into a real robot.

Robocode's API comes from Maven Central (`net.sf.robocode:robocode.api:1.9.5.6`, scope `provided`), so the build needs a network connection the first time.

## If you do not want to clone

Each lab page has a downloadable `start.zip` (in the lab's `archives` folder). Unzip it anywhere and run `mvn -B verify` inside it. It is the same project as the previous `lab-NN` folder.

## Check yourself

- You can list `course-labs` and see `lab-00`
- `mvn -B verify` in `course-labs/lab-00` ends in `BUILD SUCCESS`

You are ready for Topic 01.
