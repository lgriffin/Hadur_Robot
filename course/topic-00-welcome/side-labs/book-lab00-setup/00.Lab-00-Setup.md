# Lab 00: Set up your tools

By the end of this lab you will have Java, Maven and Robocode installed, the real Hadur robot built from source and fighting in Robocode, and the Hadur bench run once on your machine. Every later lab depends on this one.

## Objectives

- Install JDK 17, Maven 3.9, Robocode 1.9.5.6 and an IDE
- Clone the Hadur repository and build it with `mvn verify`
- Run Hadur in a Robocode battle against `sample.Crazy` and `sample.SpinBot`
- Run the Hadur bench in cold mode against the sample bots, and read its report
- Get the lab code and check that `lab-00` builds

## Steps

1. Install the tools
2. Build Hadur
3. Run a battle
4. Run the bench
5. Get the lab code

Allow about an hour, most of it downloads and the first build.
