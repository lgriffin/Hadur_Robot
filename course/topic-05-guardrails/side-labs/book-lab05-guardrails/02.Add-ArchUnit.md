# Add ArchUnit

In the **parent** `pom.xml`, add the version to `<properties>`:

```xml
<archunit.version>1.3.0</archunit.version>
```

and the dependency to `<dependencyManagement>`, next to jqwik:

```xml
<dependency>
    <groupId>com.tngtech.archunit</groupId>
    <artifactId>archunit-junit5</artifactId>
    <version>${archunit.version}</version>
</dependency>
```

In `hadurling-core/pom.xml`, add it to `<dependencies>`, test scope, without a version (the parent
supplies it):

```xml
<dependency>
    <groupId>com.tngtech.archunit</groupId>
    <artifactId>archunit-junit5</artifactId>
    <scope>test</scope>
</dependency>
```

Create the test package `hadurling.core.arch` under `hadurling-core/src/test/java`.

You may see three lines `SLF4J(W): No SLF4J providers were found` in the output. ArchUnit logs through
SLF4J and none is installed; the lines are harmless.
