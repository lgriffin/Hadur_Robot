# Wire it into the core

`Core` holds a ledger, feeds it events, and asks it at each scan. Three changes to `Core`.

## Feed the ledger

```java
if (e instanceof Event.HitByBullet) {
    surfer.hitBy(in);
    ledger.enemyBulletHitUs(((Event.HitByBullet) e).power());
}
if (e instanceof Event.BulletHit) ledger.ourBulletHit(((Event.BulletHit) e).power());
```

`Event.BulletHit` is our bullet hitting the enemy. `Event.HitByBullet` is the enemy's bullet hitting
us. Do not mix the two up: the first takes energy off the enemy, the second gives it a refund.

## Ask the ledger

Replace the naive drop test in `watchEnemyEnergy`:

```java
EnergyLedger.Reading reading = ledger.scan(scan.energy(), scan.velocity());
boolean fresh = lastScanInput != null && in.time() - lastScanTime <= 2;
if (fresh && reading.shot()) {
    double power = Math.max(EnergyLedger.MIN_SHOT, Math.min(EnergyLedger.MAX_SHOT, reading.corrected()));
    surfer.enemyFired(new Wave(lastEnemyX, lastEnemyY, lastScanTime, power, toUs, Wave.direction(lateral)));
}
```

The old `lastEnemyEnergy` field is gone. The ledger owns that memory now. The clamp is for the
floating-point edge: a corrected power of 0.0999999999 that the ledger accepted is a power-0.1 wave.

Finally make `enemyWaves()` public, because the Cucumber step lives in another package and reads it.

## Cucumber steps

Add the four steps that the scenarios in `features/hadurling.feature` need to `CoreSteps`:

```java
@Given("the core has seen an enemy with {int} energy")
public void coreHasSeen(int energy) {
    watcher = new Core();
    watcher.tick(new Input(1, 400, 300, 0, 0, 100, 0.4, 0, 0,
        List.of(new Event.Scan("foe", 0, 200, energy, 0, 0))));
}

@Given("our bullet of power {double} hits the enemy")
public void ourBulletHits(double power) {
    nextEvents.add(new Event.BulletHit("foe", power));
}

@When("the enemy is next seen with {int} energy")
public void enemySeenAgain(int energy) {
    nextEvents.add(new Event.Scan("foe", 0, 200, energy, 0, 0));
    watcher.tick(new Input(2, 400, 300, 0, 0, 100, 0.4, 0, 0, nextEvents));
}

@Then("the surfer watches {int} enemy waves")
public void surferWatches(int waves) {
    assertEquals(waves, watcher.enemyWaves());
}
```

Add a second scenario, tagged `@HL-13`, for the plain case: an enemy goes from 100 to 98 with no
hit, and the surfer watches one wave. Together the two scenarios are the acceptance test for
the fix: a drop nothing else explains is a shot, and a drop our own hit explains is not.

Last, `CoreTest` gets three unit tests tagged `HL-16`: one for a hit that explains the drop, one
for a hit plus a shot, and one for a refund.
