# Shed work in the core

`Core` feeds the budget, reads the level once per tick, and passes it down.

## Feed the budget

```java
if (e instanceof Event.TickTime) budget.tickTook(((Event.TickTime) e).nanos());
if (e instanceof Event.SkippedTurn) budget.skippedTurn();
```

These go with the other event handling at the top of `tick`.

## Read the level once

```java
int level = budget.level();
...
if (TickBudget.surfs(level) && in.time() - lastWallHit > WALL_COOLDOWN) {
    orbit.face(surfer.choose(in, orbit.direction()));
}
...
GuessFactorGun.Aim aim = gun.aim(in, scan, power,
    TickBudget.neighbours(level, GuessFactorGun.NEIGHBOURS));
```

Read it once so that every decision in a tick uses the same level. `Core` gets a public `level()` so
tests can see it.

Notice what is shed. The surfer's **prediction** is skipped at level 2, but its bookkeeping
(`advance` and `hitBy`) is not. Dropping the bookkeeping would lose waves and make the profile wrong,
and a robot that is slow but accurate is better than one that is fast and confused.

## The gun's limit

`GuessFactorGun.aim` gains a neighbour limit. The three-argument version, from lab 11, calls the
four-argument one with the full number:

```java
public Aim aim(Input in, Event.Scan scan, double power) {
    return aim(in, scan, power, NEIGHBOURS);
}

public Aim aim(Input in, Event.Scan scan, double power, int neighbours) {
    ...
    if (neighbours > 0 && usable >= MIN_SAMPLES) {
        factor = densest(tree.nearest(features, neighbours), seedWeight);
        aimAngle = wave.firingAngle(factor);
    }
    ...
}
```

With `neighbours` of 0 the gun aims head-on, which is level 3 of `HL-38`. It is the same fall-back as
`HL-11`, reached by a different road.

## Test it in the core

In `CoreTest`, tagged `HL-38`, three tests:

- feed a slow `TickTime` and check `core.level()` is 1 for that tick and 0 again after a fast one
- feed `SkippedTurn` three times, check the level reaches 3, and check the gun then aims head-on
- feed one `SkippedTurn` and check the level is 1

The whole path from adapter events to the budget to the level is covered without Robocode.
