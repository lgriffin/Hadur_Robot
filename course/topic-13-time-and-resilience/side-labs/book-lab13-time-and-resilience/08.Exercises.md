# Exercises

1. **A level 4.** Add a fourth level that also stops the wave detector. Write `HL-42` and the test
   first. What breaks if the ledger stops running while hits still arrive? (Hint: look at what it
   keeps between scans.)
2. **Recover.** Today a skipped turn costs a level until the round ends. Argue for a rule that lets
   the level fall after 50 ticks without a skip. Write the requirement, then the failing test. What
   goes wrong if it recovers too fast?
3. **The 70% line.** Change `THRESHOLD` to 0.50 and to 0.95. Which tests fail? Do they fail at the
   edge or somewhere else?
4. **Break the order.** In `ProfileLibrary.remove`, take the name out of the map before the set. Which
   tests fail? Does the property find it? How small is the shrunk case?
5. **Forget the failure.** Delete the `index = null` in the `catch` of `save`. Which test fails?
   Write the scenario in words: what would the real robot have done?
6. **A quicker fake.** `MemoryProfileStore.listings()` counts calls to `names()`. A real store has
   another expensive call: `size(name)`. Add a counter for it and write the test that a save makes
   no `size` calls for files it has already indexed.
7. **The next slide.** `ProfileLibrary.load` reads two files per opponent. If a robot met each of 300
   opponents once per battle, how many reads is that? Is it a slide? What would you count?
