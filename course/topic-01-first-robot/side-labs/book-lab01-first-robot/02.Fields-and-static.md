# Fields, and static

A robot that only spins is not much of a robot. To do more, it needs to **remember** things
between ticks. Variables that belong to an object are **fields**.

## An ordinary field

Add this near the top of the class, above `run()`:

```java
/** 1 drives forwards, -1 backwards. Flips when the robot hits a wall. */
private int direction = 1;
```

- `private` means only code inside `Hadurling` can touch it.
- `int` is a whole number.
- `= 1` is its starting value.

Each `Hadurling` object has its **own** `direction`. Robocode makes a new object for every
round, so every round starts with `direction` back at 1. For `direction` that is what we want.

## A `static` field

Now add a second field, with one extra word:

```java
/**
 * How many rounds this battle has started. {@code static}, so it belongs to the class, not
 * to one robot object: Robocode builds a new Hadurling object for every round, and a normal
 * field would start again at zero each time.
 */
private static int roundsStarted;
```

`static` means *there is one of these, shared by the whole class*, not one per object. It lives
as long as the class is loaded, and Robocode keeps the class loaded for the whole battle. So
`roundsStarted` survives from round to round, while the objects come and go.

This difference matters far beyond this lab. Whatever a robot **learns** about its enemy, such
as how it moves, must live in a `static` place or it is forgotten every round. Hadur keeps its
whole core in a static field for exactly this reason. You will see that in the Compare step.

A static field starts at the default for its type: 0 for numbers, `false` for booleans,
`null` for objects. That is why `roundsStarted` needs no `= 0`.

## Use them

At the start of `run()`, count the round and print it. `out` is a ready-made `PrintStream`
that Robocode connects to the robot's console window:

```java
@Override
public void run() {
    roundsStarted++;
    out.println("Round " + roundsStarted + " of this battle");
    // ... the loop from before
}
```

`roundsStarted++` adds one. When you run a 3-round battle the console shows rounds 1, 2 and 3.
If you remove the word `static` and run again, it shows "Round 1" three times. Try it once:
it is the quickest way to feel the difference.

## Constants

One more kind of field: a **constant**. `static final` means one shared copy that can never
change. By convention its name is in capitals:

```java
/** How far to drive on each tick, in pixels. */
private static final double STEP = 100;

/** The bullet power Hadurling always fires. */
private static final double FIRE_POWER = 1.0;
```

Use constants instead of writing `100` and `1.0` in the middle of the code. A reader can see
what the number *means*, and there is one place to change it.
