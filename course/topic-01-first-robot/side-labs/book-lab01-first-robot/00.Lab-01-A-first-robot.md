# Lab 01: A first robot

You will turn a robot that only spins its radar into one that finds its enemy, keeps it in
view, circles it and shoots at it. This is **Hadurling**, the robot you grow through the whole
course. You will also learn the handful of Java ideas the rest of the course leans on: what a
class is, what `extends` and `@Override` do, what a field is, and why one field is `static`.

You do not need to know any Robocode. You need to have written a class and a loop.

## Objectives

By the end of this lab you can:

- explain what a class, an object, a field and a method are, using the robot as the example
- say what `extends AdvancedRobot` and `@Override` give you
- explain why Hadurling has a `static` field and an ordinary one, and what each remembers
- write a robot that locks its radar on an enemy, orbits it and fires at it
- build the robot with Maven and load it into Robocode

## What you start from

The folder `course-labs/lab-00` in the Hadur repository, or the `archives/start.zip` of this
lab (which holds the same thing). It is one class, `Hadurling`, that spins its radar. Unzip it
somewhere you like, open it in your editor, and check it builds:

```bash
cd lab-00
mvn -B verify
```

You need JDK 17 or newer (Hadurling's robot code targets Java 11, its tests Java 17) and
Maven 3.9. Topic 00's lab sets both up, and installs Robocode 1.9.5.6 if you have not.

## What you will have at the end

The same folder, with `Hadurling` doing four jobs: a `static` round counter, a radar lock, an
orbit at a right angle to the enemy and a gun that fires power 1 bullets when it is cool. This
is exactly `course-labs/lab-01`. If you get stuck, copy `Hadurling.java` from there and carry
on; Lab 02 starts from it.

## The steps

1. Classes, `extends` and `@Override`
2. Fields, and `static`
3. Radar lock
4. Orbit the enemy
5. Aim and fire
6. Build and run it
7. Exercises
