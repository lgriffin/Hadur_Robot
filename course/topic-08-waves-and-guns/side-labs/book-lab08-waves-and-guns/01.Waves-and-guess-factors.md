# Waves and guess factors

When a bullet leaves a gun we know three things: where it started, when, and how fast it goes. After
`t` ticks it could be anywhere on a circle of radius `t * speed` around the shooter. That circle is a
wave.

The target was somewhere when the bullet was fired. Call the angle from the shooter to the target
the **bearing**. When the wave reaches the target, the target has moved round the circle by some
angle. The most it can move is the **maximum escape angle**. Divide the angle it did move by that
maximum and you get one number between -1 and 1: the guess factor.

- `0`: still straight ahead of the barrel
- `1`: ran at full speed the way it was already going
- `-1`: reversed and ran the other way

## Add the class

Create `hadurling-core/src/main/java/hadurling/core/model/Wave.java`. It is immutable, so it is
safe to share between the gun and the movement.

```java
public Wave(double originX, double originY, long fireTime, double power, double bearing,
        int direction) {
    this.originX = originX;
    this.originY = originY;
    this.fireTime = fireTime;
    this.power = power;
    this.bearing = bearing;
    this.direction = direction < 0 ? -1 : 1;
}

public double radius(long time) {
    return (time - fireTime) * speed();
}

public boolean hasReached(long time, double x, double y) {
    return radius(time) >= distanceTo(x, y);
}
```

`direction` is +1 if the target was circling clockwise round the shooter and -1 if anticlockwise.
It makes "forwards" mean the same thing for every wave, so guess factors from different shots can
share one tree.

The two methods that matter are inverses of each other:

```java
public double guessFactor(double x, double y) {
    double offset = Angles.normalRelativeAngle(Angles.absoluteBearing(originX, originY, x, y) - bearing);
    double gf = offset * direction / maxEscapeAngle();
    return Math.max(-1, Math.min(1, gf));
}

public double firingAngle(double guessFactor) {
    return Angles.normalAbsoluteAngle(bearing + direction * guessFactor * maxEscapeAngle());
}
```

`guessFactor` turns a place into a number. `firingAngle` turns a number back into the compass angle
to shoot at. The clamp matters: a target can appear to be beyond what is physically possible when
the scan is a tick late.

## Two helpers

`Rules.bulletSpeed` and `Rules.maxEscapeAngle` already exist from the physics lab, so the wave only
calls them. The gun and the surfer also need to project a point from a position, an angle and a
distance, so add two small methods to `physics/Angles.java`:

```java
public static double projectX(double x, double angle, double distance) {
    return x + Math.sin(angle) * distance;
}

public static double projectY(double y, double angle, double distance) {
    return y + Math.cos(angle) * distance;
}
```

Remember that Robocode angles are radians, 0 is north and they run clockwise, so x uses `sin`.

## Test it

Create `WaveTest` in the `model` test package. Fire a wave of power 3.0 from (400, 500) at a target
400 px south, and check four things: the radius grows by the bullet speed each tick, `hasReached`
flips at the right tick, a target still on the bearing has guess factor 0, and `firingAngle`
undoes `guessFactor`.

```java
private final Wave wave = new Wave(400, 500, 10, 3.0, Math.PI, 1);

@Test
@DisplayName("a target still on the bearing has guess factor 0")
void straightAhead() {
    assertEquals(0, wave.guessFactor(400, 100), 1e-12);
}
```
