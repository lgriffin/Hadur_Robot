# The learning gun

Create `hadurling/core/gun/GuessFactorGun.java`. It keeps `HeadOnGun` as its fallback. The gun does
two jobs, in this order every tick: **observe** (learn from waves that have just broken) and **aim**
(use what it has learned).

## Aim: every shot becomes a wave

```java
public Aim aim(Input in, Event.Scan scan) {
    double toEnemy = Angles.normalAbsoluteAngle(in.heading() + scan.bearing());
    double lateralVelocity = scan.velocity() * Math.sin(scan.heading() - toEnemy);
    double[] features = {lateralVelocity / 8.0, scan.distance() / 800.0};
    Wave wave = new Wave(in.x(), in.y(), in.time(), POWER, toEnemy, Wave.direction(lateralVelocity));

    double factor = 0;
    double aimAngle = toEnemy;
    if (tree.size() >= MIN_SAMPLES) {
        factor = densest(tree.nearest(features, NEIGHBOURS));
        aimAngle = wave.firingAngle(factor);
    }
    double turn = headOn.turn(in, aimAngle);
    double power = headOn.power(in, turn);
    if (power > 0) inFlight.add(new Shot(wave, features, factor));
    return new Aim(turn, power);
}
```

The **features** are what describes a situation: how fast the enemy is moving sideways, and how far
away it is, each scaled to roughly 0 to 1 so that neither dominates the distance. The
`if (tree.size() >= MIN_SAMPLES)` line is requirement `HL-11`: with fewer than five samples there is
nothing to learn from, so `aimAngle` stays at `toEnemy`, which is head-on.

Only a shot that really fires (`power > 0`) is kept as a wave in flight.

## Observe: learn when the wave breaks

```java
for (int i = inFlight.size() - 1; i >= 0; i--) {
    Shot shot = inFlight.get(i);
    Wave w = shot.wave;
    if (in.time() - w.fireTime() > MAX_WAVE_AGE) {
        inFlight.remove(i);
    } else if (w.hasReached(in.time(), ex, ey)) {
        double gf = w.guessFactor(ex, ey);
        tree.add(shot.features, gf);
        ...
        inFlight.remove(i);
    }
}
```

When the wave reaches the enemy we ask `guessFactor` where it was found and file that number in the
tree under the features recorded at fire time. Waves older than 200 ticks are dropped, because by
then the enemy was out of sight when the bullet would have arrived.

Notice that the gun learns from every wave that reaches the enemy, whether or not the real bullet
hit. That is why it learns so much faster than a gun that waits for hits.

## Pick the densest guess factor

The ten nearest neighbours each carry a guess factor. The gun fires at the one with the most other
guess factors close to it:

```java
double z = (a.value() - b.value()) / BANDWIDTH;
density += Math.exp(-z * z);
```

A few odd shots do not pull the aim off a clear favourite. Everything here is deterministic, which
the replay test depends on.
