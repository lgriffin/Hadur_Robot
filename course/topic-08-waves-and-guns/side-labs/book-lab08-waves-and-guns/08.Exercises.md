# Exercises

1. **Tune the neighbours.** Change `GuessFactorGun.NEIGHBOURS` from 10 to 3 and then to 50. What
   happens to the aim in `GuessFactorGunTest`? Which value would you pick for an enemy that never
   changes its pattern, and which for one that does?
2. **Another feature.** Add a third feature to the gun: the distance to the nearest wall, scaled to
   0..1. The tree needs three dimensions. What do you have to change, and which tests tell you?
3. **Show the weakness.** Write a test that adds 1000 points in sorted order to a `KdTree` and
   counts how many nodes a search visits. Compare with the same points added in a random order.
   What would you change to fix it?
4. **A missing row.** Write requirement `HL-14` for the 20-tick wall cooldown in `Core`, in EARS,
   and tag a new test for it. Which pattern is it?
5. **Break the surfer.** In `Surfer.choose`, swap the `<` for `>`. Which tests fail? Does any
   property or example catch it, or only a battle?
6. **Fire power.** The gun always fires at `HeadOnGun.POWER`. List two things that make a fixed
   power a bad idea. (Lab 11 starts to answer this.)
