# Orders: NaN means leave it alone

`Orders` is what the brain wants done this tick. A tick may not touch every setting: the body
may keep turning as ordered earlier, while we only adjust the gun. So each setting needs a way
to say "no change". We use `Double.NaN`: a legal `double` that is never a real order.

Create `src/main/java/hadurling/model/Orders.java`.

## The private constructor and the named constant

```java
    public static final Orders NONE = new Orders(Double.NaN, Double.NaN, Double.NaN, Double.NaN, 0);

    private final double bodyTurn;
    private final double ahead;
    private final double gunTurn;
    private final double radarTurn;
    private final double firePower;

    private Orders(double bodyTurn, double ahead, double gunTurn, double radarTurn,
            double firePower) {
        this.bodyTurn = bodyTurn;
        this.ahead = ahead;
        this.gunTurn = gunTurn;
        this.radarTurn = radarTurn;
        this.firePower = firePower;
    }
```

`NONE` is a ready-made value that changes nothing and holds fire (a power of 0). The constructor
is `private`: the only ways to get an `Orders` are `NONE` and the **builder**.

## A builder

An `Orders` has five numbers. A call like `new Orders(NaN, 100, 0.2, NaN, 1)` is unreadable:
which is which? A builder names each one:

```java
Orders o = Orders.builder().ahead(100).fire(1).build();
```

Anything you do not set stays NaN, or 0 for the fire power. The builder is a small class nested
in `Orders`, with a method per setting that **returns itself**, so calls chain:

```java
    public static final class Builder {
        private double bodyTurn = Double.NaN;
        private double ahead = Double.NaN;
        private double gunTurn = Double.NaN;
        private double radarTurn = Double.NaN;
        private double firePower;

        private Builder() {}

        /**
         * @param radians the body turn, clockwise positive
         * @return this builder
         */
        public Builder bodyTurn(double radians) { this.bodyTurn = radians; return this; }

        /**
         * @param px the distance to drive, negative to reverse
         * @return this builder
         */
        public Builder ahead(double px) { this.ahead = px; return this; }
        // ... and one method like it for each of the other four settings
    }
```

A **static factory method** (`Orders.builder()`) is a static method that returns a new object,
here instead of a public constructor. It lets the class decide what to build and gives the
call a readable name.

Write the getters, `equals`, `hashCode` and `toString` as for `Input`. In `equals`, `NaN`
equals `NaN` through `Event.same`; that is how the test "these orders leave the gun alone" can
be written with `assertEquals`.

## Meaning of each field

| Field | Unit | Meaning |
|---|---|---|
| `bodyTurn` | radians | turn the body, clockwise positive |
| `ahead` | px | drive, negative to reverse |
| `gunTurn` | radians | turn the gun |
| `radarTurn` | radians | turn the radar; may be infinite, meaning "keep turning" |
| `firePower` | energy | 0 holds fire; otherwise the bullet power |
