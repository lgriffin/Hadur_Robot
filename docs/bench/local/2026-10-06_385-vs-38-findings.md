# Hadur 3.8.5 against 3.8 in 1v1 (local bench, 2026-10-06)

3.8.5 (PR #116) scoped the DrussGT route to the duels it was built for (MATCH-1, MATCH-2). In the
duel arena nothing should move. This run checks that, on the same footing as the 3.8 live-loss
bench (issue #113): Robocode 1.11.1, CPU constant 1488498, parallel 12 with two CPUs a child,
35 rounds, paired by seed, baseline `bisect/hadur2.Hadur_3.8.jar`. The harness was the one on
master before #118, so the rows carry no duress or host-load columns.

## Conditions

Four RoboRumble workers were running on the PC throughout, so the load is higher than in the
earlier runs. Skipped turns per battle were the same for both builds in each run, so the
comparison is fair; the level is not comparable with earlier runs.

| Run | Battles per build | Skipped turns per battle, 3.8.5 | 3.8 |
|---|---|---|---|
| Leak set (32 robots) | 512 | 16.7 | 16.7 |
| Top 20 | 100 | 28.0 | 27.2 |
| DrussGT | 20 | 42.2 | 38.2 |

## Result: 3.8.5 minus 3.8, score share, points (`data/tools/analyse.py`)

| Run | Pooled per battle | Opponent-clustered | Opponents resolved (Holm) |
|---|---|---|---|
| Leak set, 16 seeds x 32 | -0.26 +/- 0.35 [-0.62, +0.09] | -0.26 +/- 0.32 [-0.59, +0.06] | 1 of 32 (pez.nano.Icarus, +1.25) |
| Top 20, 5 seeds x 20 | -1.12 +/- 1.56 [-2.68, +0.45] | -1.12 +/- 2.02 [-3.14, +0.91] | 0 of 20 |
| DrussGT, 20 seeds | -0.41 +/- 3.66 [-4.08, +3.25] | not defined (one opponent) | 0 of 1 |

Reading:

- **No change is resolved.** Every pooled interval spans zero. On the leak set the interval is
  tight enough to say 3.8.5 is within a point of 3.8 (TOST with a 1.0 point margin: equivalent,
  p < 0.0001). That is the expected result for a change aimed at melee and team.
- **Top 20 cannot say.** Five seeds give a pooled half-width of about 1.6 to 2.0 points, so the
  margin test does not pass (p = 0.56). The point estimate is -1.1; the largest per-opponent
  moves (Tomcat -4.7, Phoenix -7.7, Saguaro -4.9) are inside their intervals except Tomcat
  (unadjusted p = 0.005, Holm 0.09). A larger top-20 sample is queued for the overnight run.
- **DrussGT:** -0.4 +/- 3.7 at 20 seeds, no difference found. The 3.8.5 change should leave this
  duel on the route it had, and the data does not contradict that.
- The Icarus gain (+1.25 +/- 0.57, Holm-adjusted p 0.009) is the one per-opponent difference that
  survives correction across the 32 robots. It is a small gain against a robot Hadur already beats
  at 96 to 97%, and 3.8.5 has no change aimed at it, so treat it as a lead to repeat, not a finding.
