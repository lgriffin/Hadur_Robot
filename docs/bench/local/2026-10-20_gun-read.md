## What Hadur's duel gun is, against Diamond 1.8.22's

Hadur's main gun is Diamond's `MainGun`: the displacement-vector KNN (K = size/10 up to 100,
Gaussian kernel at twice the bot width) that Diamond 1.8.22 uses **only in melee**
(`DiamondFist.initGuns`: `_enemiesTotal > 1`). In a duel Diamond fires:

| | Diamond 1.8.22 duel | Hadur 3.13 duel |
|---|---|---|
| Main gun | `TripHammerKnnGun`: guess factors scaled by the precise escape angle, K = size/9 up to 225, neighbours weighted 1/sqrt(distance), 59 candidate angles, cube kernel (1 - u^3) at twice the bot width, `TripHammerFormula` (10 features incl. bullet power) whose weights slide from `INITIAL_WEIGHTS` to `FINAL_WEIGHTS` as the view grows (`FINAL_TIMES`) | `MainGun` (melee displacement gun, Gaussian kernel, `GunFormula` fixed weights) |
| Opening | `PerceptualGun` for the first 9 data points: a 1,000-point trained kd-tree of guess factors, no learning | head-on for nine waves (ADAPT-1), then the ratings |
| Anti-surfer | `AntiSurferGun`, four views, K/10 | the same port |
| Gun choice | `bestGun`: the highest rating, switched every shot, no margin | GUN-1: the best only once it clears every other candidate's Agresti-Coull margin |
| Rating | plain hits/shots for the battle | 100-shot half-life decay (GUN-1), plus the GUN-4 hybrid and GUN-5 sampled guns |

So the surf is Diamond's duel surf, but the gun is Diamond's melee gun. The TripHammer gun was
Diamond's own replacement for the displacement gun in duels (1.7 to 1.8), kept because it hit
more; its data form (guess factor x precise escape angle) is also what the anti-surfer and hybrid
guns already use here, so the view machinery exists (`KnnView.setWeights` is there).

## Stage 3's switches (all duel-only, off by default; melee and team untouched)

| Code | Switch | What it does |
|---|---|---|
| `th` | GUN-8 TripHammer main gun | In a duel the MAIN gun aims from a TripHammer view (formula, K, weights schedule, kernel and candidate grid as Diamond 1.8.22); the displacement view keeps logging for seeds and profiles; the MAIN rating is the TripHammer's. |
| `fg` | GUN-9 free gun choice | `liveVerdict` returns the best-rated candidate with no margin test (Diamond's `bestGun`), both power classes. |
| `nd` | GUN-10 undecayed ratings | GunStats without the 100-shot decay: lifetime hits over shots, as Diamond. |

Screen on the 149 at 4 seeds against 3.14hjsw (th, fg, nd, thfgnd), the usual top-50 guard on
the best, keep rule +1.0 on the class with the interval above 0; then the whole-field census of
the keeper against 3.13 at the +0.3 gate. The gun matters on the whole field, not only here:
the 432 flat x learning robots are 1.70 of the 3.03 APS to DrussGT, so a main-gun change is the
one stage-3 candidate that can clear a release gate on its own.

Expected: Diamond's dealt edge on the class is +2.4 a round, about +1 pp of share, +0.12 APS
from the 149 and perhaps +0.3 to +0.5 on the field if the gun's edge carries to the 432. The
flips' fallback movement is the test case: th should lift the late hit rate on them above
16%; if it does not, the gun that does is ScalarR's, which is not a port.
