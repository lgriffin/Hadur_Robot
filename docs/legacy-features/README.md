# Legacy feature files (Hadur 1.x)

These Cucumber features describe Hadur 1.17's behaviour (radar, movement, targeting,
melee). They are kept for reference only and are not run: Hadur 2's feature files live in `hadur-core/src/test/resources/features/`, one per EARS group,
with each scenario tagged by the requirement IDs in [../requirements.md](../requirements.md).
